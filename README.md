# SDGP Project

A plain HTML, CSS and JavaScript site. There is nothing to install or build.

## Files

```
index.html     the page
css/style.css  styles (follows the system light/dark mode)
js/main.js     scripts
favicon.ico    browser tab icon
```

## Running it

Open `index.html` in a browser.

For auto-reload while editing, use the **Live Server** extension in VS Code: right-click `index.html` and choose **Open with Live Server**.
